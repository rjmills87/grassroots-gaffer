# Grassroots Gaffer - Production Deployment Guide

This guide provides step-by-step instructions for deploying the Grassroots Gaffer MVP to a production environment.

## Prerequisites

- Production server with PHP 8.2+ and Node.js 22+
- Database server (MySQL/MariaDB recommended for production)
- Web server (Nginx or Apache)
- Domain name configured
- SSL certificate (Let's Encrypt recommended)
- Email service configured (SMTP, Mailgun, Postmark, etc.)

## Application Deployment

### 1. Clone Repository

```bash
cd /var/www
git clone <your-repository-url> grassroots-gaffer
cd grassroots-gaffer
```

### 2. Install Dependencies

```bash
# Install PHP dependencies
composer install --optimize-autoloader --no-dev

# Install Node dependencies
npm ci

# Build production assets
npm run build
```

### 3. Environment Configuration

Create `.env` file from template:

```bash
cp .env.example .env
```

Configure production environment variables (see Environment Variables section below).

### 4. Generate Application Key

```bash
php artisan key:generate
```

### 5. Configure Database

Update `.env` with production database credentials, then run migrations:

```bash
php artisan migrate --force
```

**Note:** Use `--force` flag in production to skip confirmation prompts.

### 6. Optimize Application

```bash
# Cache configuration
php artisan config:cache

# Cache routes
php artisan route:cache

# Cache views
php artisan view:cache

# Generate Ziggy routes for frontend
php artisan ziggy:generate
```

### 7. Set Permissions

```bash
# Set ownership (adjust user/group as needed)
sudo chown -R www-data:www-data /var/www/grassroots-gaffer

# Set directory permissions
sudo find /var/www/grassroots-gaffer -type d -exec chmod 755 {} \;

# Set file permissions
sudo find /var/www/grassroots-gaffer -type f -exec chmod 644 {} \;

# Make storage and cache writable
sudo chmod -R 775 /var/www/grassroots-gaffer/storage
sudo chmod -R 775 /var/www/grassroots-gaffer/bootstrap/cache
```

## Web Server Configuration

### Nginx Configuration

Create `/etc/nginx/sites-available/grassroots-gaffer`:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;
    root /var/www/grassroots-gaffer/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;

    charset utf-8;

    # SSL Configuration
    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

Enable the site:
```bash
sudo ln -s /etc/nginx/sites-available/grassroots-gaffer /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Apache Configuration

Ensure mod_rewrite is enabled and create virtual host configuration.

## Queue Worker Setup

For production, run queue workers to process emails and background jobs:

```bash
# Using Supervisor (recommended)
sudo apt install supervisor
```

Create `/etc/supervisor/conf.d/grassroots-gaffer-worker.conf`:

```ini
[program:grassroots-gaffer-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/grassroots-gaffer/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=1
redirect_stderr=true
stdout_logfile=/var/www/grassroots-gaffer/storage/logs/worker.log
stopwaitsecs=3600
```

Start supervisor:
```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start grassroots-gaffer-worker:*
```

## Troubleshooting

### Application Not Loading

1. Check file permissions
2. Check web server configuration
3. Check Laravel logs: `storage/logs/laravel.log`
4. Verify `.env` configuration
5. Clear caches

### Emails Not Sending

1. Verify mail configuration in `.env`
2. Check queue worker is running
3. Check mail logs
4. Test SMTP connection

### Assets Not Loading

1. Run `npm run build`
2. Check `public/build` directory exists
3. Verify web server can serve static files
4. Clear browser cache
